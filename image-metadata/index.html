      What this does and doesn't do

      • Nothing is uploaded. Every byte is read and rewritten in your browser. The page makes no network requests at all — which is worth checking, because "remove EXIF online" sites ask you to upload the exact photo whose location you're trying to hide.
      • The pixels are not touched. This isn't a re-save. The compressed image data is copied across byte for byte and only the containers around it are rewritten, so a stripped JPEG decodes to exactly the same image at exactly the same quality. Tools that "remove metadata" by re-encoding quietly cost you quality every time.
      • It shows you first. You can see what was in there, what's being removed and what is being kept, before you download anything.
      • Colour profiles are kept by default. They aren't personal data, and dropping them changes how the image looks. There's a checkbox if you want it gone anyway.
      • One caveat: if a photo relies on an EXIF orientation flag to display upright, removing the metadata will leave it sideways. The page warns you when that's the case, and the resizer can bake the rotation into the pixels instead.
      • Not included: editing metadata, adding a copyright tag, or stripping metadata from video. Those are different jobs.

      The parser and the stripper are plain, testable JavaScript, checked against hand-built files with known metadata at known offsets: node tests/image.mjs.
